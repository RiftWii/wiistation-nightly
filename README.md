# WiiStation nightly

Daily builds of [WiiStation](https://github.com/xjsxjs197/WiiSXRX_2022) from its newest
commit, for the [Rift Store](https://github.com/RiftWii/apps),
RiftWii's homebrew store. A new one is made only when upstream has changed,
and each one is a release with its own tag and the exact source it came
from.

These are not official releases. Problems with WiiStation itself belong
upstream: https://github.com/xjsxjs197/WiiSXRX_2022/issues
